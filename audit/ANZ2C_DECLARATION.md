## Причина (ANZ2b)
Ось строилась по области гистерезиса, разросшейся до клеток с оценкой 0,06: путь шёл по середине этой области, а не по
объекту; сглаживание 60 м срезало изгибы. Карта 0…1 насыщена (плато 1,0 поперёк ленты), гребня на ней нет.

## Построение ANZ2c
1. **Сырой выход сети** `logit` (до сигмоиды) — те же карты, тот же `predict`, только без сигмоиды. Пороги переводятся
   в logit без изменений: верх = logit(0,9930), низ = logit(90 % карты подделки Б листа) — как ANZ1b/ANZ2b (`Q_LOW`).
2. **Гребень**: гессиан logit со σ = 1 клетка (20 м, `RES_IN`); клетка — гребень, если наименьшее собственное
   значение < 0 и сглаженный logit не меньше соседей вдоль нормали (±1 клетка, линейная интерполяция). Только годные клетки.
3. **Отбор гребней**: гребень ∧ (logit ≥ низ) → скелет → связные части (8 соседей), в которых есть клетка ≥ верх.
4. **Линии**: длинные пути по графу (как ANZ2b, п. 2: самый длинный путь, снять, повторить, куски ≥ 200 м).
5. **Без сглаживания и без мостиков** (сшивка — отдельным объявлением, если понадобится).

## Мера (как ANZ1/ANZ2/ANZ2b, описательно)
Та же цепочка на подделке Б → км Б / км снимка, по листам, сводно, Утсйоки отдельно; (а) врезки в Утсйоки (план 3400,
ширины ANZ2) узкие/прежние, 5 корзин, 20 сдвигов. Печать: км, число линий, извилистость (медиана, 90 %), замкнутые
ячейки, клетки линий вне годных (ожидается 0); рядом ANZ2 и ANZ2b. Числа после прогона не двигаются.
Новое число одно — σ гребня = 1 клетка (наименьший масштаб; не подбиралось — в пробе был только он).
