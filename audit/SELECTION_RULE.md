# Правило выбора окон для рисунков (Пакет 01 ТЗ К1)

Записано **26.10.2026, до построения и просмотра окон.** После просмотра
правило не меняется. Если окно окажется плохим, оно остаётся в наборе, а
причина записывается в `selection_manifest.csv`.

## Что считается допустимым окном
- Квадрат **5 × 5 км** (250 × 250 ячеек по 20 м). Это тот же размер, что у
  окон для глазной проверки ветки.
- Центры окон стоят на регулярной сетке с шагом 2.5 км.
- Окно допустимо, если **100 % его ячеек валидны**: есть зимний композит
  (а на Анабаре ещё и обе модели рельефа) и до края листа не меньше 2.5 км.
- Линии при отборе **не используются никак**: ни число, ни длина, ни
  плотность. Эталон GTK на Лапландии тоже не используется.

## Анабар — три окна
1. **Случайное:** равновероятно из всех допустимых.
2. **Пологий рельеф:** случайное из допустимых окон, у которых медиана
   уклона GLO-30 ниже 25-го процентиля медиан всех допустимых окон.
3. **Расчленённый рельеф:** то же выше 75-го процентиля.

Уклон — вход метода, разрешённый с 21.10.2026. Страты взяты по требованию ТЗ:
«низкий/высокий рельеф». 25-й и 75-й процентили — квартили распределения,
а не подбор. Пересекаться окна не могут: если очередное окно перекрывает
уже взятое, берётся следующее по тому же генератору.

## Лапландия — два окна
1. **Случайное:** из всех допустимых.
2. **Случайное** второе. Страт по рельефу нет: модель рельефа для Лапландии
   не скачивалась, а скачивать её ради выбора окна — лишний вход.

Воду как страту не беру ни там, ни там. Маски воды нет, а строить её по
снимку значит использовать снимок для выбора, глядя на него.

## Генератор
`numpy.random.default_rng(20261026)`. Для каждой площадки свой поток: в
начале площадки генератор создаётся заново с тем же зерном. Порядок: страты в
том порядке, как перечислены выше.

## Панели
- **Анабар:** зимний снимок B04 без линий / тот же снимок + линии по снимку
  (весь лист, C_all) / тот же снимок + линии рельефа, добавленные к снимку
  (DEM1, add).
- **Лапландия:** снимок без линий / снимок + наши линии (весь лист) / снимок
  + наши линии + GTK 292. GTK стоит только на этой оценочной панели.

Все панели одного окна имеют одинаковые рамку, масштаб, проекцию и растяжку
яркости. Растяжка — процентили 2–98 % по всему листу, а не по окну. Оси
подписаны координатами в метрах проекции, на каждой панели есть масштабная
линейка.
