# REAL2 — «линия настоящая» по независимым свидетелям: исправленная мера (доля побед в симметричных парах)

Записано 16.11.2026, до кода. Решение Артура: «давай, делай REAL2». Повод — REAL1 не прошёл
калибровку (`audit/REAL1_RESULTS.md`): оценка Стори по рангам среди 8 сдвигов смещена (на шуме
5–15 %). Рецепт — консультант (Fable 5.2), проверен его симуляциями. Лидар не используется.

## Что сохраняется из REAL1
Площадка Утсйоки, сетка 20 м; наборы UTS1, RELU1, LINB2 (`C_all`); свидетели S1 (VV, среднее
половин), S2 лето (B04, NDVI; 8 дат, слой `s2w_summer`), Landsat лето (красный, NDVI), рельеф
(GLO-30 и ALOS — **один свидетель «рельеф»**, когерентны 0,96–0,99). Статистика линии T: отклик
`L = σ²(|nᵀHn| − |tᵀHt|)₊` по нормали n и касательной t линии (PCA), σ ∈ `SIGMAS` = 1, 2 ячейки,
каждый кандидат (поле × σ) нормирован на медиану |наибольшего собственного числа| по листу;
максимум по боковому смещению ±6 ячеек (120 м — целая часть правила 127 м); среднее вдоль линии;
T свидетеля — максимум по кандидатам. Линия выбывает, если > 50 % её ячеек вне маски свидетеля.

## Что меняется
1. **Маска свидетеля сужается на 8 ячеек** (4σ при σ = 2: гауссово ядро гессиана обрезается на 4σ,
   `truncate` по умолчанию) — у края маски залитые медианой пустоты дают ложные ступени.
2. **Нуль — симметричная пара сдвигов по нормали ±d.** Для линии
   `w = (c(T₀, T₊d) + c(T₀, T₋d)) / 2`, c = 1 (больше), 0,5 (равно), 0 (меньше). **Оценка доли
   настоящих π̂ = 2·среднее(w) − 1, без обрезки** (может быть отрицательной). При стационарном
   поле E[w] = 1/2 для любой линии, не являющейся особой, — ноль по симметрии, независимо от
   зависимости сдвигов. **Основная пара — d = 13 ячеек (260 м = 2·6 + 1, окна ±6 не
   пересекаются)**, ближе всех к линии (тот же тип местности). Для сведения — d = 19, 25, 32
   (380, 500, 640 м) и π̂ по дальности: рост с дальностью = тип местности, не линия.
3. **Интервал** — блочный бутстреп по центрам линий, блоки 12 км (итог) и 6 км (справка), 1000
   повторов, 2 зерна; «не меньше X %» = нижний край 95 % по блокам 12 км (худшее из зёрен).
4. **Строки по наборам.** UTS1: (а) «другая физика» — S1, S2 лето, Landsat; (б) «рельеф» — GLO-30 +
   ALOS одним свидетелем: «вдоль линии есть форма рельефа» (форма это или линеамент —
   классификация, потом). RELU1 и LINB2: S2 лето, Landsat; S1 печатается с пометкой «зависим»
   (S1 RTC выправлен по GLO-30). «Хотя бы одним» = максимум нижних краёв по независимым
   свидетелям; справочно — общий T (максимум по кандидатам всех независимых свидетелей).

## Допуск меры к запуску (до чтения наборов; при провале — выход без расчёта наборов)
Линии — объединение трёх наборов (настоящие геометрии), поля — синтетические на сетке листа:
(а) белый шум; (б) суррогат каждого поля каждого свидетеля со случайными фазами (амплитудный
спектр — а значит длина корреляции — из самого поля, не выбранное число). R = 5 реализаций (выбор
дизайна; по замеру консультанта SE одной ≈ 1,3–1,8 п. п.). **Условие: для (а) и для каждого
свидетеля (б) |среднее π̂ по R| ≤ 2·SE** (SE = стандартное отклонение по R / √R). (в) Суррогат (б),
умноженный на огибающую — местный разброс настоящего поля в окне `LOCAL_WIN_M` = 2 км (окно
нормировки тракта), — не обязан быть нулём: его π̂ — **«пол фактуры»**, печатается рядом с
итогом; итог читается «сверх пола».

## Контроли на данных
- **Отрицательный (тор)**: наборы сдвинуты по диагоналям (±3,4 км, ±3,4 км; 3,4 км = p95 длины
  RELU1 2,61 км + 762 м, как в REAL1; диагонали — потому что сдвиги по осям уже увидены в REAL1);
  линии, перескочившие край листа, выбрасываются. **Критерий: 95 % интервал π̂, сводной по
  4 направлениям, содержит 0.** Рядом печатается «потолок плотности» = доля ячеек сдвинутых линий
  в 127 м от исходных × π̂ набора: значение выше потолка — смещение меры, ниже — плотность линий.
- **Положительный**: линии `trace` по S2 лето (B04), свидетель Landsat лето (другой сенсор и даты
  того же сезона). **Критерий: нижний край ≥ 0,5** (прежний порог устойчивости ветки). S2 → S2 —
  только проверка кода.
- **Ориентационный**: те же линии наборов с переставленными n и t в отклике L (сдвиги — по
  прежней нормали). Ожидается π̂ ≤ 0 (мера чувствует направление); печатается.

## Как читается
Описательно, `REAL2_N_TESTS` = 0 (p-проверок нет; условия допуска и контролей — условия
приёмки меры, не гипотезы о наборах). Итог: «не меньше X % линий набора подтверждены независимым
свидетелем (сверх пола фактуры Y %)», только если допуск и отрицательный контроль пройдены;
иначе — «мера не откалибрована», без процентов. Слово «ложные» не используется. REAL2 — мера,
не фильтр: отбор линий по ней — отдельное объявление.

## Поправка 1 (по проверке openlin-registrar, 16.11.2026, до кода)
Источники чисел проверены: 8 яч. = 4σ (σ = 2, `SIGMAS`, обрезка гауссова ядра `truncate` = 4);
13 = 2·6 + 1; 19 = 13 + 6; 25 = 13 + 12; 32 ≈ 2,5·13 (640 м = 32·20 м, справка, не критерий);
6 км = половина 12 км (справка); 3,4 км = 2,61 км + 762 м (762 = 6·127, REAL1); 2 км = `LOCAL_WIN_M`;
127 м — предел сдвига сшивки (OPENLIN_RULES). Лист 3850×4300 яч. (77×86 км): блоков 12 км ≈ 45–50.
Выбор дизайна, без замера: R = 5, 1000 повторов, 2 зерна, порог 0,5 (прежний порог устойчивости).
1. **E[w] = 1/2 — условия.** Нужна обменность пары (T₀, T_d), а не только равенство законов T₊ и T₋:
   она следует из стационарности и центральной симметрии закона поля (C(h) = C(−h), любая
   анизотропия допустима) и из прямой линии. Ломают: (i) кривая линия (сдвинутые копии ±d имеют разную
   форму и длину); (ii) асимметрия склона/дисперсии по нормали; (iii) линия на границе типов
   местности (T₀ в «шероховатом» классе, один из сдвигов — в другом: w смещён вверх, это не
   линия, а граница). Суррогат со случайными фазами даёт стационарное гауссово поле и проверяет
   только случай (0); (i)–(iii) видит лишь тор-контроль. Мера читается как «вдоль линии есть
   край/хребет в поле свидетеля», границы типов местности она не отличает от линий.
2. **Допуск: 2·SE заменяется на t₀,₉₇₅(4) = 2,776·SE.** При R = 5 SE сам оценён по 4 степеням
   свободы; при истинном нуле «2·SE» даёт ложный провал ≈ 11,6 % на проверку, а проверок ≈ 8
   (шум; S1; S2 B04, NDVI; Landsat красный, NDVI; GLO-30 и ALOS как один свидетель — считать 1)
   — совместный ложный провал ≈ 50 %. С 2,776·SE — 5 % на проверку (≈ 30 % на все). Печатать
   среднее и SE в п. п.; провал при |среднее| ≤ 1 п. п. — не критерий смещения, а недобор R:
   тогда допускается увеличить R до 15 **один раз, до чтения наборов, одним решением для всех
   проверок** (не по одной).
3. **Суррогаты.** Использовать ту же маску свидетеля (с сужением 8 яч.) и тот же `valid`, что на
   данных; GLO-30 и ALOS — с **общими случайными фазами** (иначе нарушена когерентность 0,96–0,99,
   и «один свидетель» превращается в четыре независимых кандидата); регистр: линии у края листа
   (где FFT-суррогат периодичен) — те же допуски края `admissible`, что на данных. Допуск также
   на сдвинутые копии: линия идёт в расчёт, только если все три положения (0, +d, −d, с окном ±6
   → до 19 яч.) лежат в маске свидетеля; иначе w считается по неполным сдвигам и смещён. Это правило
   применяется и на данных, и в симуляции.
4. **Тор-контроль.** Критерий «95 % интервал содержит 0» слаб, если интервал широк: печатать число
   блоков 12 км и точку π̂ по 4 направлениям; отдельно (справка) π̂ по каждому направлению.
   Линия, часть клеток которой перескочила через край, выбрасывается целиком. «Потолок плотности»
   — оценка сверху в предположении, что совпавшие линии подтверждены как среднее по набору;
   в критерии не участвует, только печатается.
5. **Положительный контроль.** S2 B04 и Landsat — оба оптика одного сезона (общие тени, растительные
   края): проходной контроль показывает, что мера видит край, а не независимость свидетеля.
   Провал (нижний край < 0,5) → «чувствительность меры не подтверждена», проценты по наборам
   печатаются с этой пометкой (мера недооценивает — «не меньше X %» остаётся оценкой снизу,
   но без утверждения о долях). **Ориентационный**: критерий — нижний край π̂ ≤ 0 не выше 0; если
   > 0 — мера чувствует не направление, итог помечается. Печатается.
6. **Итог** выдаётся только при пройденных допуске и тор-контроле (как в основном тексте). «Хотя
   бы одним» = максимум нижних краёв по 2–3 свидетелям — это отбор по максимуму, смещён вверх; в
   итоге писать и нижний край по каждому свидетелю отдельно, не только максимум.
7. Счётчик: `REAL2_N_TESTS` = 0; префикс-цепочка не расширяется (p-проверок нет); ссылок на
   `*_N_TESTS_PRIOR` не нужно. `git fetch`: новых коммитов на origin/lineaments нет.
