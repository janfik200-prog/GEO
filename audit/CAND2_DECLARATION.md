# CAND2 — кандидаты для Анфисы: пороги рабочего тракта (нормировка по окрестности 2 км)

Записано 19.11.2026, до кода. Решение Артура: «давай, делай CAND2». Повод — CAND1 не принят
(`audit/CAND1_RESULTS.md`): (в2) 59,8 % < 68,0 %. Причины (аудитор): порог по фазовой подделке встаёт на
уровень крупных долин рельефа (подделка гауссова, настоящий отклик «хвостатый»); глобальный порог снимка
набивает пул краями пятен снега/леса. Лидар не используется. `CAND2_N_TESTS` = 0.

## Что НЕ меняется (как CAND1)
Пять каналов и их отклики/нормали (`openlin_cand1.response`: признаки Анфисы 1, 2, 3, 6, 7; IMG_SIG_M,
DEM_SIG_M, GRAD_SIG_M), `nms`, `hysteresis8`, скелет, `branches`, `stitch20` (900 м / 127 м / 20°, конец
300 м), длина ≥ 200 м; каналы не сливаются; входы — зимний S2 `shade` и GLO-30.

## Что меняется (только порог) — правило рабочего тракта как есть
`openlin_iso.axial_local_with_support` (рабочий тракт ветки, OPENLIN_RULES «Текущий метод»; правило
21.09.2026 «локальный порог», окно выбрано без перебора — комментарий над `LOCAL_WIN_M`):
1. отклик канала → `openlin_iso.local_norm(r, valid, 20 м, LOCAL_WIN_M = 2000 м)` (логарифм отклика в сигмах
   окрестности 2 км);
2. уровни `Q_HIGH`/`Q_LOW` = 97 / 90 % — квантили **нормированного отклика самого листа** (а не подделки);
3. nms по нормали канала, гистерезис по z, как в CAND1.
Подделка (тот же код, тот же порог z-квантилей подделки по её собственной нормировке) — **только справка**
(км подделки / км канала), как поправка 2 CAND1: правило «≤ 20 %» здесь не критерий (у CAND1 мерило
негауссовость; переносить его без замера нельзя).

## Условия приёмки на Утсйоки (те же, что CAND1, пороги не трогаются)
(б) короткие хорды у осей ≤ 6,7 % + 2·SE по каналу и пулу; n < 100 — «не оценено»; печатается, приёмку
не решает (как CAND1, поправка 2).
(в1) GTK 292 в 300 м от пула ≥ 68,0 %; (в2) при равной длине 6826 км (случайное прореживание линий, 20
повторов, зерно 1900) средняя ≥ 68,0 %. **Принято, если (в1) и (в2).**
Для сведения: км и км/км² по каналам, GTK по каналам, LINB6 в 60/127 м, прежний пул ↔ CAND2, CAND1 ↔ CAND2,
видимость в ≥ 2 каналах; **доля ячеек после гистерезиса, ушедших в куски < 200 м** (проверка «рвёт ли
нижний порог тонкие штрихи», CAND1 окно 5); то же для окна 5 отдельно.

## Поправка 1 (registrar), 19.11.2026, до кода
Сверено с кодом и CAND1. `origin/lineaments` нового не имеет (fetch 19.11). Источники: 97/90 % =
`openlin_iso.Q_HIGH/Q_LOW`; окно 2000 м и 20 м — `LOCAL_WIN_M` и сетка листа (импортировать, не
переписывать); остальные числа — как CAND1 (68,0 %, 6826 км, 20 повторов, зерно 1900, 6,7 %). Новых чисел
нет. `CAND2_N_TESTS` = 0 допустимо (p-проверок нет, настройка; в цепочку RELU4 = 160 не входит).
1. **Нужен замер до кода (ловушка eps).** `local_norm` берёт `log(r + eps)`, `eps` = квантиль 1 % отклика
   (минимум 1e-9). Отклики каналов 1, 2, 4, 5 в `openlin_cand1.response` — положительная часть
   (`np.maximum(sign*lam, 0)`), т.е. заметная доля ячеек точно 0. Если нулей > 3 % (уровень Q_HIGH) —
   `eps` = 1e-9, `log` = −20,7 в каждой такой ячейке, локальные среднее и σ определяются долей нулей в
   окне, а не силой гребня: z у ненулевых ячеек ≈ √((1−p)/p), порог выберет места с малой долей нулей.
   Рабочий тракт брал `ridge_response` (другой отклик) — перенос «как есть» без проверки не доказан.
   Замер (Утсйоки, 5 каналов, скрипт в `GEO_scratchpad/cand/`): доля нулей по каналу, `eps`, корреляция z с
   локальной долей нулей. Если нули > 3 % — объявить ДО прогона одну фиксированную замену (напр. нормировать
   только по ненулевым ячейкам окна / `eps` = квантиль 1 % по ненулевым), одно, без перебора; иначе CAND2 не
   «правило тракта как есть».
2. **Второй подбор на той же площадке.** Да, это вторая попытка на Утсйоки после провала (в2) CAND1; число
   не подбирается (правило и окно взяты из тракта, определены 21.09 до CAND1), поэтому счёт не растёт, но
   записать: Утсйоки — площадка настройки, попыток по порогу пула 2 (CAND1, CAND2); принятие на Утсйоки
   основанием для Анабара не служит. **Третья попытка по порогу — только с новым источником (замер, не
   «стало хуже») и записью, что настройка на Утсйоки исчерпана.** Нет права менять 68,0 %/6826 км по
   результату.
3. **Достижимость (в2).** Планка 68,0 % — полнота прежнего пула, он сам её даёт на 6826 км, т.е. достижима по
   построению; для CAND2 не измерена, замер = сам прогон (p-порога нет, 20 повторов — только оценка
   среднего). Км пула CAND2 определяет квантиль, а не данные (3 % ячеек выше Q_HIGH на лист на канал): если
   км < 6826 — прореживание не нужно, сравнивается сырая полнота при своей длине (честнее для CAND2: если
   она ≥ 68,0 % при меньшей длине — (в2) выполнено; иначе нет). Записать это правило сейчас.
4. **Тавтологии.** (в1) тавтологична по густоте (как в CAND1) — решает (в2). Подделка справкой; «км
   подделки/км канала» при локальной нормировке по построению близко к 1 для пары «квантиль по своей
   нормировке» (оба листа получают ~3 % ячеек) — не читать как чистоту. Доля ячеек, ушедших в куски
   < 200 м, — для сведения, порог не вводить.
5. **Охотник — до аудитора обязательно** (CAND1 пропустил), в т. ч. на швы нормировки по окну 2 км (края
   маски, границы окон у снега/леса).
