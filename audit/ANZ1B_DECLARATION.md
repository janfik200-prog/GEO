# ANZ1b — линии по карте ANZ1 заново: гистерезис, сшивка до отсева, отсев по длине связной линии

Записано 24.11.2026, до кода. Решение Артура: «делай оба шага по очереди» (шаг 1 — линии, шаг 2 — ANZ2, тонкие линии).
Повод — глазной просмотр Артура (окна 1 и 3 Анабара, 8 отмеченных мест) и замер на карте ANZ1 Анабара: клеток с
оценкой ≥ 0,5 — 505 км², из них в 60 м от линий 28 %; ≥ 0,8 — 361 км², 37 %; даже ≥ порога 0,9854 — только 72 %.
Отметки Артура — **только картинка для глаз**: ни одно число ниже по ним не выбирается и не проверяется. `ANZ1B_N_TESTS` = 0.

Сеть, карты, зёрна подделок, порог 0,9854 — **из ANZ1 без изменений** (сеть `outputs/fam/anz1/anz1_net.pt` загружается,
не переобучается; карты пересчитываются той же функцией с теми же зёрнами). Меняется только путь «карта → линии».

## Что меняется в линиях (ANZ1 → ANZ1b)
1. **Гистерезис вместо одного порога.** Область = связные (8 соседей) части `карта ≥ нижний уровень`, в которых есть хотя
   бы одна клетка `≥ 0,9854`. Нижний уровень = 90-й процентиль карты подделки Б того же листа — это уже объявленный в ANZ1
   уровень мостика (`Q_LOW` = 90 %, гистерезис ветки 97/90); новых чисел нет. Тот же уровень остаётся порогом мостика.
2. **Ось = скелет области** (медиальная ось). «Гребень карты» по поперечному максимуму не берётся: карта насыщена —
   30 % клеток выше порога имеют оценку ≥ 0,999 (замер на Анабаре), поперёк ленты плато, максимум не определён.
3. **Куски не отсеиваются до сшивки.** Мостики LIRA ищутся между концами всех ветвей скелета (≥ 2 клеток), геометрия и
   правило те же, что в ANZ1 (разрыв ≤ 900 м, сдвиг ≤ 127 м, угол ≤ 20°, слабое звено ≥ нижнего уровня, один мостик на конец).
4. **Отсев после сшивки — по связной линии**, а не по ветви между развилками: остаются все ветви связных частей итоговой
   маски длиной ≥ 200 м (`LINK_MIN_LEN_M`). В ANZ1 ветвь < 200 м между двумя развилками выбрасывалась и рвала сеть линий.

## Мера (как ANZ1, описательно)
Та же цепочка на подделке Б того же листа → км подделки / км снимка (до и после сшивки), по листам обучения, Утсйоки,
Анабару, сводно. (а) врезки в Утсйоки (план 3400) по 5 корзинам + 20 тороидальных сдвигов (зерно 3500). Печать: км линий,
доля карты ≥ 0,5 / ≥ 0,8 / ≥ порога в 60 м от линий (покрытие, на снимке и на Б), число мостиков и их км.
Ожидание (не условие): покрытие растёт, доля шума тоже может вырасти — нижний уровень пропускает больше клеток Б.
Если доля шума на Утсйоки станет выше 0,40 (SYN1b) — это записывается как результат, порог не двигается.

## Запреты и подпись
Как ANZ1: «описательная карта; отношение подделка/снимок — оценка доли неотличимого от шума метода снизу, не точность»;

## Поправка 2 (моя), 24.11.2026, до прогона — по проверке кода на куске карты Анабара 1300×1300 (без снимка Б, не мера)
1. **Мостики при гистерезисе пусты по построению.** Область — связные части «карта ≥ нижнего уровня»; путь между двумя
   разными частями обязательно проходит клетку ниже уровня, значит его слабое звено < порога мостика (тот же уровень).
   Всё, что LIRA сшила бы на этом уровне, гистерезис уже соединил. Код мостиков оставлен, число печатается (ожидается ≈ 0);
   ниже уровня мостик не опускается — это было бы новое число.
2. **Концы для мостиков — только тупики** (клетка скелета с одним соседом). Ветви `branches` не включают клетки развилок,
   поэтому конец ветви у развилки — не конец линии (на куске он давал 279 «мостиков» в 0 км новых клеток).
3. **Маска линий = скелет целиком** в оставленных связных частях (с клетками развилок). В ANZ1 маска собиралась из ветвей
   и рвалась на каждой развилке (на куске 205 → 238 км при той же геометрии). Старая цепочка ANZ1 печатается рядом как есть.
4. **Чистка срединной оси**, один проход: отросток (тупик — у развилки) убирается, если его длина ≤ толщины области у
   развилки (2 × расстояние до края области, distance transform). Новых чисел нет: мера — сама толщина ленты. На куске:
   отростков 439 (101 км) → после чистки 181 (82 км). Печатаются отростки после чистки.
Отметки Артура при этом не открывались; кусок — лист обучения, числа куска в итог не идут.
