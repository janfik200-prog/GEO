## D11. Семейства нулевых проверок

Это четыре разных протокола. Поправка 0.05/N применяется только к первому.

| Семья | Что проверяет | Сдвиги / подделки | Поправка |
|---|---|---|---|
| **1. Внутренний счётчик ветки, 124 проверки** | Четыре безэталонных условия тракта (мусор, сдвиговый нуль, устойчивость, длина) | 5000 сдвигов в тракте, подделки IAAFT; пол p = 1/5001 | **да:** α = 0.05/124 = 0.000403 для finland65; 0.05/118 = 0.000424 для Лапландии |
| **2. Сверка с GTK (исходный протокол 25.10)** | Полнота по слою 292 при 300 м, два набора («в зонах», «весь лист») | **159** сдвигов, зерно 2510; пол p = 1/160 | своя: 2 проверки, α = 0.025; в счётчик 124 не входит |
| **3. GTK, 5000 сдвигов (Пакет 05)** | То же, большим числом сдвигов | **5000**, зерно 2511; пол p = 1/5001 | нет, разведочная |
| **4. Условные нули (Пакет 05)** | Нуль по местности: 159 из 5000, ближайших по воде и уклону; страты «у воды / вдали» | из пула п. 3 | нет, **post hoc** |

Эталоны v1 и v2 сверяются своими 159 сдвигами (пол 0.0063). В поправку они
тоже не входят.

**Допустимые сдвиги (семьи 2–4).**
- Сдвиг растра эталона по тору. По каждой оси целое число ячеек из
  [m, n − m], где m = min(200, n/8). Значит, сдвиг не меньше 4 км и не почти
  полный круг.
- В счёт идут только ячейки эталона, попавшие после сдвига в валидную
  область.
- p = (1 + k) / (1 + B), где k — число сдвигов с полнотой не ниже
  наблюдаемой.

**Искажения тора измерены.** У эталона GTK 45 % ячеек у воды, у сдвигов
30.6 ± 2.6 %. Нуль по местности довёл долю только до 35 %. Поэтому
стратифицированные нули подаются отдельно, как диагностика.

**Сырые сдвиги есть на обеих финских площадках.**
- Файлы: `outputs/k1/results/gtk_shifts.csv` (Лапландия) и
  `outputs/k1/results/finland65/gtk_shifts.csv`.
- В каждом по 5000 строк на набор: dy, dx, полнота, доля у воды, уклон,
  отбор по местности.
- Исходных 159 сдвигов от 25.10 нет. Новые 159 — повтор правила, а не
  реплика.
