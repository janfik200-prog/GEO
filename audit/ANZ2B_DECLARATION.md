# ANZ2b — чёткие линии по карте ANZ2: оси уверенных клеток, длинные пути вместо скелета-паутины, прямые мостики LIRA

Записано 24.11.2026, до кода. Артур: «карта Анфисы стала лучше, анзалира всё ещё работает плохо: вместо чётких линий куча
завитушек странной формы». Глазной отзыв — повод, не мера. Сеть ANZ2 (`outputs/fam/anz2/anz2_net.pt`) не переобучается;
карты снимка и подделки Б пересчитываются той же функцией и зёрнами; порог карты 0,9930 — из ANZ2. `ANZ2B_N_TESTS` = 0.

## Причины завитушек (из ANZ1b/ANZ2, охотник)
Скелет широкой области (ширина 89–118 м) даёт петли и отростки; гистерезис до 0,06 добавляет бледные места; путь LIRA по
клеткам петляет внутри коридора. Тысячи замкнутых ячеек, извилистость 1,8–2,2.

## Построение линий ANZ2b
1. **Область — только уверенные клетки** `карта ≥ 0,9930` (без гистерезиса).
2. **Скелет → граф → длинные пути.** В каждой связной части скелета (8 соседей) берётся самый длинный путь (геодезический
   диаметр); его клетки снимаются, из оставшихся кусков той же части снова самый длинный, пока куски ≥ 200 м
   (`LINK_MIN_LEN_M`). Петли этим разрываются, отростки короче 200 м отпадают. Числа — только 200 м.
3. **Сглаживание линии**: координаты вдоль линии сглаживаются гауссом с σ = 60 м (`CONF_TOL_M` — допуск ветки
   «линия на объекте»); печатается максимальное и 99 % смещение точек (ожидание ≤ 60 м; если больше — записывается).
4. **Мостики LIRA**: между концами линий (только концы путей), геометрия сшивки ветки (разрыв ≤ 900 м, сдвиг ≤ 127 м,
   угол ≤ 20°); проход по карте — путь max-min (`widest_path`) со слабым звеном ≥ нижнего уровня = 90 % карты подделки Б
   (`Q_LOW`, как ANZ1/ANZ1b). Здесь мостик не пуст по построению: области — клетки ≥ 0,9930, уровень прохода ниже.
   **Рисуется прямой отрезок** между концами (путь только подтверждает проход). Каждый конец — один мостик, жадно.
   После сшивки соединённые линии сливаются и сглаживаются заново (п. 3).
5. Итог — линии ≥ 200 м.

## Мера (как ANZ1/ANZ1b/ANZ2, описательно)
Та же цепочка на подделке Б → км Б / км снимка до и после сшивки, по листам, сводно, Утсйоки отдельно; (а) врезки
в Утсйоки (план 3400, ширины ANZ2) узкие/прежние, 5 корзин, 20 сдвигов; печать: км, число линий, мостики (число, км),
извилистость (длина / хорда, медиана и 90 %), развилки и замкнутые ячейки (должны быть 0), смещение сглаживания.
Рядом — ANZ1 и ANZ2 из их итогов. Порог и уровни не двигаются после прогона.

## Запреты и подпись

## Поправка 1 (registrar), 24.11.2026, до кода
Fetch: новых коммитов на origin/lineaments нет. Последнее звено — RELU4 154+6=160; `ANZ2B_N_TESTS` = 0 верно, констант счётчика не заводить; (а) — 20 сдвигов, p не считается, условием не служит.
1. **Источники.** 200 м = `LINK_MIN_LEN_M`; 0,9930 = порог ANZ2; 900 м / 127 м / 20° = сшивка ветки; `Q_LOW` = 90 % карты Б (ANZ1). Новое только σ = 60 м.
2. **σ = 60 м допустимо при оговорках.** `CONF_TOL_M` — допуск «линия на объекте» и граница метки (≤ 60 м = 1), то есть бюджет положения, а не масштаб кривизны; для σ гаусса источник слабый, но это не подбор по картинке: цель — «не сдвинуть линию дальше допуска». Гаусс σ = 60 м сдвигает точки на изгибах больше, чем σ не гарантирует ≤ 60 м, поэтому проверка смещения (max, 99 %) — это условие, а не только печать: если max > 60 м, писать «сглаживание вышло за допуск» и не менять σ после прогона. Других σ не пробовать.
3. **Скрытая подгонка под глаз.** Выбор шагов (область без гистерезиса, пути, σ, прямые мостики) — реакция на отзыв Артура; каждый шаг обоснован причинами из ANZ1b/ANZ2, но «чётче» ≠ «вернее». Не называть результат улучшением; сравнение с ANZ2 — только описательное.
4. **Смещение меры.** Сглаживание и длинные пути укорачивают извилистые линии сильнее, чем прямые; подделка Б извилистее, значит «км Б / км снимка» падает отчасти от самой чистки. Печатать км до и после сглаживания/выбора путей (и для снимка, и для Б), не только итог; отношение читать как оценку снизу, «шум снизился» не выводить.
5. **Прямые мостики** могут выходить из коридора (до 127 м): печатать долю мостиков, у которых отрезок не лежит целиком в клетках ≥ нижнего уровня, и длину мостиков в км и в % от всех линий (подделка Б — отдельно). «Не пуст по построению» — свойство построения, не результат.
6. **Печатать:** км/число линий (снимок, Б, до/после каждого шага), мостики, извилистость, развилки/замкнутые ячейки (0), смещение сглаживания, (а) узкие/прежние с числом врезок, ANZ1/ANZ1b/ANZ2 из итогов. Подпись и запреты — как ANZ2. Вердикт: принимается при п. 2, 4, 5.

## Поправка 2 (моя), 24.11.2026, до прогона — по пробе кода на окне 3 Анабара (лист обучения, 8×8 км; не мера)
1. **Область — гистерезис, как ANZ1b** (семена ≥ 0,9930, рост по клеткам ≥ 90 % карты подделки Б листа), а не только
   ≥ 0,9930. Причина (замер на пробе): при одной области ≥ 0,9930 ленты рвутся на куски, а мостики почти не проходят —
   из 96 пар концов 88 отсекает условие угла ±20° (изогнутые ленты), итог 21 км против 69 км у гистерезиса. Паутину ANZ1b
   теперь убирает п. 2 (длинные пути вместо скелета), а не уровень. Новых чисел нет: уровень — уже объявленный `Q_LOW`.
   **Честно:** на том же окне я смотрел и уровень 0,5 (линии ровнее); не взят — это был бы выбор глазом без источника.
2. Мостики оставлены (при гистерезисе ожидается ≈ 0, как ANZ1b; на пробе 1 мостик, 0,1 км).
3. Сглаживание заново — только для цепочек, слитых мостиком; остальные сглаживаются один раз (двойное сглаживание
   укорачивало линии). На пробе: смещение 99 % 24 м, макс 34 м (≤ 60 м); извилистость медиана 1,09, 90 % 1,84.
4. Печать по поправке 1: площадь области; км путей → после сглаживания → после отсева 200 м → после сшивки, для снимка и
   Б; смещение (99 %, макс); извилистость; мостики.
