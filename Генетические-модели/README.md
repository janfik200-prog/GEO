# Генетические модели оруденения

Рабочие тексты генетических моделей — основа предметной модели
(`docs II presentation/План-обучение-на-знаниях.md`, шаг 1).

Порядок:
- одна модель — один файл `.md` (рядом собирается `.docx`); новая редакция
  записывается поверх, прежние остаются в истории репозитория;
- в шапке файла — номер версии, дата получения, от кого, пометка «не
  окончательная», если модель ещё дополняется;
- текст хранится дословно; всё, что добавлено при разборе (заголовки,
  толкования, классификация типа), помечается как не из исходника;
- исходные файлы (как пришли) — в `исходники/` с датой в имени;
- последнее слово по модели — за руководителем проекта.
