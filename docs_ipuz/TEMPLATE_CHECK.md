## Осознанные отклонения

1. **Разделы статьи.** В шаблоне структурных заголовков нет — только сплошной
   текст. Оставлены заголовки ВВЕДЕНИЕ … ЗАКЛЮЧЕНИЕ (14 пт, по центру,
   полужирные): они не противоречат шаблону и нужны для чтения научного
   текста. Убираются одной правкой, если принимающая сторона потребует.
2. **Метка «Аннотация.» / «Abstract.»** В шаблоне абзац аннотации идёт без
   метки. Метка оставлена для однозначности.
3. **Текст таблиц — 11 пт.** Шаблон кегль внутри таблиц не задаёт; 11 пт
   выбран, чтобы таблицы 1 и 2 укладывались в ширину полосы.
4. **E-mail в статье не печатается.** В шаблоне поля для адреса нет; контакт
   передаётся через форму регистрации. Если потребуется, добавляется строкой
   в `authors.json`.
5. **Интервал подписи таблицы — одинарный** (в шаблоне у этого абзаца 1,5).
   Полуторный интервал в одной строке подписи ничего не меняет, кроме высоты.

## Вёрстка последней страницы

Английский блок не оставляется один на отдельной странице: литература и
английская часть склеены как один неразрывный блок
(`experiments/ipuz_article.py::склеить_хвост`), а ширины рисунков подобраны
так, чтобы страницы заполнялись ровно — `ШИРИНА_РИСУНКОВ = (14.5, 11.0, 11.0)`
см. Итог: 8 страниц, последняя заполнена на 84 % (литература плюс английский
блок), ни одной страницы с заполнением ниже 74 %.
