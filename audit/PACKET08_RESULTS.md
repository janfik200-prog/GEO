## 1. Что сохраняет двойник тракта (IAAFT по листу, 8 итераций)

| | Анабар | Лапландия |
|---|---|---|
| Гистограмма: расстояние К–С снимок / двойник | 0.0026 | 0.0030 |
| Радиальный спектр: двойник / снимок по 20 кольцам | 0.97–1.05 | 1.00–1.05 |
| Спектр направлений: наибольшая разность доли сектора из 12 | 0.0005 | 0.0000 |
| **Неоднородность** (CV локального ст. откл. 2 км): снимок | **0.745** | **0.283** |
| то же у двойника по листу | **0.230** | **0.137** |
| то же у двойника по участкам 20 км | 0.459 | 0.171 |

**Чтение.**
- Двойник почти точно сохраняет гистограмму, спектр и **анизотропию** —
  спектр направлений совпадает.
- Значит, «линии» двойника — это то, что даёт текстура с той же
  ориентированностью, но без фазовой структуры. Сравнение с ним справедливо
  к направленной фактуре: она в двойнике есть.
- Двойник **разрушает неоднородность** по площади: в 3.2 раза на Анабаре, в
  2.1 раза на Лапландии. Плато и долины, озёрные и лесные участки в нём
  смешаны.

**Глазом** (`surrogate_windows_*.png`): двойник по листу — одинаковая
пятнистая текстура во всех окнах. Двойник по участкам сохраняет местную
фактуру; в окне 1 Анабара у него есть даже косая штриховка снимка. Швы
участков видны, линии у них исключены из счёта.

## 2. Нуль строже: IAAFT по участкам 20 × 20 км (разведочный)
Мусор этапа подтверждения (подделка / снимок), три подделки. Линии у границ
участков исключены у обеих сторон.

| | Анабар, в зонах | Анабар, весь лист | Лапландия, в зонах | Лапландия, весь лист |
|---|---|---|---|---|
| Двойник по листу (900–902) | 8.3 % | 4.9 % | 0.0 % | 0.6 % |
| **Двойник по участкам (1900–1902)** | 4.1 % | **6.7 %** | 0.0 % | **5.8 %** |
| Порог | 20 % | 20 % | 20 % | 20 % |

Линий подделки до подтверждения (весь лист, среднее):
- Анабар — 724 по листу и 643 по участкам при 3152 у снимка;
- Лапландия — 269 и 392 при 2673.

**Чтение.**
- **Все наборы проходят порог при обоих нулях.** Вывод «подтверждение
  отсеивает шум» от выбора нулевой модели не зависит.
- Но для всего листа строгий нуль даёт мусор **выше**: на Лапландии в 10 раз
  (0.6 % → 5.8 %), на Анабаре в 1.4 раза. Число «мусор 0.6 %» отражает
  мягкость глобального двойника, а не только качество тракта.
  **Для статьи: давать диапазон по двум нулям** — Лапландия 0.6–5.8 %, Анабар
  4.9–6.7 % по листу.
- Глобальный двойник в этих условиях воспроизводит рабочий прогон: 8.3 / 4.9 %
  против 8.2 / 4.8 % в логе TWIN. Разница — исключённые линии у границ.

## 3. Врезки (`injection_azimuth.png`)
- **После правки, режим «контраст»** — сырые исходы 96 × 5. При амплитуде
  ≥ 8σ все азимуты дают 75–100 %. Ложных при нуле — 1 из 96 (азимут 98°).
- **После правки, режим «высота»** (одинаковый уступ, солнце 184°) —
  остаётся провал у меридиана:
  - 8° — 0–25 % при любой амплитуде;
  - 172° — 25–75 %.

  Это физика освещения, а не код.
- **До правки** — отчётный агрегат из таблицы лога, сырых нет. Провалы на
  8°, 82°, 98°, 172° — осях растра — в обоих режимах. Это след ошибки
  утончения.

## 4. Регрессионный тест утончения (`tests/test_nms_orientation.py`, 2 теста, проходят)
