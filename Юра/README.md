# Юра — опорные материалы

Тексты, заметки, файлы и решения, которые присылает Юра. На них опираемся
при развитии проекта.

Порядок:
- материалы кладутся сюда как есть, с датой получения в имени файла
  (`ГГГГ-ММ-ДД_тема.расширение`);
- к каждому поступлению — строка в журнале ниже: что пришло, о чём, к какому
  блоку плана относится (`docs II presentation/План-обучение-на-знаниях.md`);
- материалы — опора и аргумент, а не готовое решение: **последнее слово за
  руководителем проекта**. Если материал расходится с ранее принятым
  решением, расхождение записывается в журнал и выносится на решение, а не
  применяется молча.
