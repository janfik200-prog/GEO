# ACON1 — линии «от противного» (a contrario): линия засчитывается, если случайно такая встречается реже раза на лист

Записано 23.11.2026, до кода. Решение Артура: разметка геологов — только заверка, не учитель («так нельзя…
нужно использовать его для заверки»); «давай попробуем 1 направление» (a contrario); «давай, делай ACON1».
Лидар не используется. `ACON1_N_TESTS` = 0: порог NFA — правило обнаружения, а не проверка гипотезы против
эталона; GTK и разметка в выбор не входят.

## Источники
Desolneux–Moisan–Morel (принцип Гельмгольца), детектор LSD (Grompone von Gioi и др., 2012), применение к
линеаментам — Sidiropoulou-Velidou и др., Math. Geosci. 2015 (база знаний, doc 10.1007_s11004-015-9584-z):
FAR = (N·M)^{5/2}·B(n, k, p), p = τ/180°, τ = 22,5°. Отличие ACON1: ничего не подбирается по эталону (у них —
по эксперту); зависимость соседних точек учитывается шагом, выбранным по подделке.

## Замер до объявления (`C:/projects/GEO_scratchpad/cand/acontrario_probe.py`, лог рядом; Утсйоки)
p(«черта канала есть И её направление в ±τ от направления линии») = 2τ/π · P(отклик > 0) — совпадает с замером
на снимке и подделке (τ = 22,5°: 0,22–0,25). «Хоть в одном из 5 каналов» — 0,74 (неразличимо) → каналы
проверяются раздельно. Связь соседних точек R(d) почти одинакова на снимке и подделке (её задают фильтры);
спад: перепад ~100–140 м, полосы ~240–300 м, рельеф ~500–600 м; на подделке остаток ~1,05–1,1 и дальше.

## Метод
1. **Проверяемые линии.** Все линии CAND2 по каналам (до отбора дублей; Утсйоки 34 889), каждая — в своём канале.
   Отрезок проверки — главная ось линии (`eigh` ячеек), от минимальной до максимальной проекции.
2. **Точки.** На оси через шаг d_ch (канал ch), n точек; точка «совпала», если в ней отклик канала > 0 и
   направление черты (нормаль + 90°, `openlin_cand1.response`) в ±τ от направления оси; k — число совпавших.
3. **NFA** = N_тестов · B(n, k, p_ch), N_тестов = число проверенных линий листа (все каналы), p_ch = 2τ/π ·
   P(отклик_ch > 0) по листу (формула, проверенная замером). τ = 22,5° (LSD, статья). Линия засчитана при NFA ≤ 1.
4. **Шаг d_ch — по подделке, а не руками.** Подделка А (фазовая, зерно 2311+канал): те же шаги 1–3 на линиях,
   проведённых тем же трактом CAND2 по подделке; **d_ch — наименьший лаг из сетки замера (20, 40, …, 200, 240,
   300, 400, 500, 600, 800 м), при котором в канале ch на подделке А засчитано 0 линий.** Если ни при каком лаге
   не 0 — канал исключается (запись).
5. **Достижимость (печать до прогона на снимке):** наименьшее n, при котором даже k = n даёт NFA ≤ 1:
   n_min = ⌈ln N / ln(1/p)⌉; наименьшая длина линии = n_min · d_ch по каналам. Короче — не обнаружимо по построению.

## Условия на Утсйоки (настройка)

    засчитанных линий по 5 каналам ≤ 3 (98 % квантиль Пуассона со средним 1 — арифметика порога NFA ≤ 1).
    Провал (а) — модель фона неверна: дальше не идём, переходим к эмпирическому порогу (запись в итог).
(б) **Чувствительность (для сведения):** врезка прямых уступов/полос 4 км на 12 азимутах в снимок и рельеф
    при амплитудах 1, 2, 4, 8 σ (как `openlin_artifact_site_floor`) — доля обнаруженных.
(в) **Описание:** число и км засчитанных линий по каналам; NFA-распределение; сравнение с CAND3 (сколько
    засчитанных среди CAND3, сколько CAND3 не засчитано); покрытие LINB6 в 127 м; GTK 292 в 300 м — только для

    рельеф + то же). Охотник — до окон. Аудитор — после.

## Анабар
Только если (а) пройдено на Утсйоки: те же правила; шаги d_ch выбираются по подделке А **Анабара** (правило, не
число), проверка — подделка Б Анабара (то же условие ≤ 3, описательно). Картинки и описание.

## Протокол заверки разметкой (записан до неё; разметка открывается один раз)
Набор для заверки — засчитанные линии ACON1 листа, где есть разметка (код и шаги заморожены, sha в логе).
Совпадение — точка линии в t от линии геолога и направление в ±τ (как в статье: расстояние и направление);
t — 127 м (`TWIN_OFFSET_M`) или медиана расхождения двух геологов, если одно окно размечено дважды (выбор по факту
наличия двойной разметки). Меры: полнота = доля длины линий геологов, покрытая засчитанными; точность = доля длины
засчитанных, покрытая линиями геологов; потолок = то же для всех проверенных линий. Сравнения при равной длине:
случайные проверенные линии (20 повторов, зерно 1900, среднее и мин–макс), CAND3 целиком (своя длина), LINB6. Без
p-проверок; если они понадобятся — отдельное слагаемое от prior 160.

## Поправка 2 (моя), 23.11.2026, до кода — ошибка соглашения об углах в замере
Проверка на синтетической полосе: в соглашении ядер ветки (направление (строка, столбец) = (−cos a, sin a)) угол θ из
`openlin_cand1.response` — **это уже направление черты**, а не нормаль. В объявлении («нормаль + 90°») и в первом
замере было θ + 90° → связь соседей R(d) мерилась ПОПЕРЁК черт. p от этого не меняется (направление линии случайно).
Замер переснят с θ (лог `acontrario_probe.log`; прежний — `acontrario_probe_ОШИБКА_поперёк.log`). Вдоль черт связь
спадает медленнее: τ = 22,5°, подделка, R(800 м): полосы 1,08, перепад 1,02, ложбина 1,30, гребень 1,28 (снимок близко).
Поэтому: (i) в методе направление черты = θ; (ii) сетка лагов дополняется 1000, 1200, 1600, 2000 м (рельеф не
вышел на плато к 800 м; это разрешение поиска, правило выбора d — поправка 1 п. 2 без изменений); (iii) достижимость
(п. 3 поправки 1) печатается с новыми d; при d рельефа ~1–2 км минимальная длина 8–16 км — ожидается, что каналы
рельефа обнаружат только очень длинные линии или будут исключены (записать, не подгонять).
