# WP14. Задание на следующее исследование — внешняя территория

Конференционная работа отвечает на узкий вопрос: какую часть рисунка
экспертной критериальной карты воспроизводят дистанционные признаки на одном
листе. Следующая работа должна отвечать на вопрос, который здесь остался
недоказуемым: сохраняется ли это соответствие там, где критериальная карта и
независимые геологические свидетельства существуют **раздельно**.

## 1. Что замораживается до переноса

Переносить надо готовое, а не подбирать заново. До начала фиксируются и не
меняются:

* набор 38 входов (37 признаков переноса + индикатор наличия спектра);
* порог маски обнажённости 2 %;
* постобработка: ранговая калибровка внутри полосы, сглаживание ядром
  5 × 1,25 км с простиранием на северо-запад;
* гиперпараметры модели;
* определение O₁₀ и процедура снятия квадратичного тренда.

Любое изменение из этого списка создаёт новый `run_id` и отдельную таблицу
сравнения; замороженный результат остаётся доступным для проверки.

## 2. Выбор территории

Годится участок, где выполняются три условия:

1. есть критериальный расчёт по стандартизованной методике — чтобы повторить
   измерение O₁₀ и отделить качество исходной карты от качества алгоритма;
2. есть независимые геологические события: рудопроявления, задокументированные
   не через ту же карту;
3. район геологически отличается от Анабарского щита настолько, что перенос
   является испытанием, а не продолжением интерполяции.

Варианты по убыванию предпочтительности: внешняя частично размеченная площадь
с геологоразведочными проявлениями; другой лист со стандартизованным
критериальным расчётом; ретроспективное испытание на опубликованном наборе
месторождений со строгой пространственной группировкой.

**Источник истины не должен совпадать с картой, использованной для обучения.**

## 3. Что измеряется

| Величина | Зачем |
|---|---|
| O₁₀ к новому критериальному расчёту | прямое продолжение текущей работы |
| hit rate и PR-AUC по независимым меткам | то, чего нельзя измерить на основном листе |
| связь выделенных зон с геологическими свидетельствами | содержательная проверка |
| калибровка вероятностей | пригодность для принятия решений |
| сдвиг распределения признаков (domain shift) | объяснение провала или успеха |
| область применимости модели | где предсказание вообще допустимо |

Группировать для пространственной проверки надо **по независимым районам**, а
не по ячейкам: большое число ячеек не заменяет числа территорий. Доверительные
интервалы по одному району не распространяются на другие.

## 4. Отрицательные метки

Отсутствие разведанной руды отрицательной меткой не является. Нужны
геологически осмысленные контролируемые фоновые точки с описанным правилом
отбора. Искусственные месторождения не создаются ни при каких обстоятельствах.

## 5. Если внешних меток не нашлось

Честный результат в этом случае — анализ сдвига распределений, области
наблюдаемости и точности имитации критерия на новом листе, без каких-либо
заявлений об обнаружении. Переносить внутренние проценты в качестве
доказательства геологической полезности нельзя.

## 6. Чего нет на основном листе и чем это не заменяется

* геохимия (ореолы Au, pathfinder-элементы As/Sb/Hg/Bi/Te/Mo/Ni) — отсутствует
  полностью; открытых слоёв не существует, канал через фонды закрыт;
* аэрогамма-спектрометрия K/eU/eTh — подтверждена как значимая именно для
  Билляхской тектоно-флюидитной зоны, но данные не опубликованы.

Оба пробела — отсутствие данных, а не недоработка сбора. Вычислить их из уже
собранного нельзя, и дистанционные признаки их не замещают.

## 7. Разделение причин ошибки

Для журнальной публикации требуется разделить три источника расхождения:
качество исходной критериальной карты на новой территории, сдвиг данных и
ограничения самого алгоритма. Без этого разделения отрицательный результат
переноса ничего не объясняет.
