# ГМО v2 на широкой территории: что нанесено и что нет

21.10.2026. Карты — `outputs/13_генетическая_модель/gmo_wide_*.png` (17 штук,
скрипт `experiments/gmo_v2_wide.py`). Территория — широкая сетка 500 м
(5 листов R-48: V,VI / IX,X / XI,XII / XV,XVI / XVII,XVIII), подложка ГГК-200,
граница щита по карте Арктики 1:5 млн. Слои формулы — «⚠ с осторожностью».

## Нанесено

| № | Элемент ГМО | Канал | Покрытие широкой сетки | Замечание |
|---|---|---|---|---|
| 01 | I.2 интрузии | остаточное магнитное поле `gm_mag_ost_35` | 76% | на северо-западном листе R-48-IX,X магнитной съёмки нет |
| 02 | I.2 интрузии | аналитический сигнал `pf_mag_asig` | 76% | то же |
| 03 | I.3 разломные зоны | плотность линеаментов `lin_dens` | 100% | |
| 04 | I.3 разломные зоны | градиент гравитационного поля `gm_gr_1G_25` | 100% | сглажен, видны только крупные структуры |
| 05 | I.4 диафторез | ASTER Mg-OH 2.33 мкм | 21% | съёмка на 70%, обнажено 30%; видны межсценовые ступеньки (юг листа R-48-XV,XVI) |
| 06 | II.3–4 изменения пород | ASTER индекс изменений | 21% | то же |
| 07 | II.3–4 изменения пород | Sentinel-2 окислы железа | 30% | только обнажённые ячейки |
| 08 | II.5 складчатость | анизотропия линеаментов | 22% | только где есть линеаменты |
| 09 | II.6 коры выветривания | ASTER каолинит | 21% | как 05 |
| 10 | III.7–8 осадки | положение в рельефе (TPI 2 км) | 100% | заменитель, не литология |
| 11 | III.7–8 осадки | изрезанность рельефа | 100% | заменитель |
| 12 | III.7–8 осадки | радар ALOS PALSAR HH | 100% | заменитель |
| 13 | сохранность (нет в v2) | высота | 100% | |
| 14 | I.2 интрузии | ⚠ дайки (формула) | полоса 105–108° | западнее 105° нет |
| 15 | I.3 разломные зоны | ⚠ зоны СЗ и СВ (формула) | полоса 105–108° | западнее 105° нет |
| 16 | II.6 коры выветривания | ⚠ коры (формула) | полоса 105–108° | кор почти нет — 0.6% площади сборки |
| 17 | III.7–8 осадки | ⚠ фации и палеодолины (формула) | полоса 105–108° | западнее 105° нет |

Заверка на всех картах: ореолы Au (только основной лист) и 12 шлихов с Au на
юго-западе — только для сверки, не признак.

Проверено: на границе основного листа ступеньки в данных нет (медианы по обе
стороны отличаются меньше чем на 0.3σ); разница в оттенке на картах — от
подложки ГГК-200 под полупрозрачным слоем.

## Не нанесено и почему

| Элемент ГМО | Почему не нанесён |
|---|---|
| I.1 Золотоносные кварцевые жилы | Жилы мельче ячейки 500 м; кварцевый индекс теплового ASTER проверен ранее и закрыт отрицательно. Прямо видны только как пробы и шлихи — а это заверка |
| I.3 как источник / канал / ловушка | Модель даёт зоне три роли, но все три видны одним и тем же слоем; разделить их нечем |
| I.4 вне обнажений | ASTER меряет поверхность; под растительностью (70% территории) сигнал снят, там элемент не наблюдается |
| II.1–2 Разрушение, денудация, палеорельеф | Современный рельеф палеорельеф не наследует — проверено ранее отрицательно; палеодолины есть только как слой формулы |
| II.3–4 Выщелачивание как химический процесс | Нужна геохимия (вынос Au и спутников) — её нет; спектры показывают изменение пород, а не вынос золота |
| III.1–6 Наследование факторов | Это связь между этапами, а не объект на карте; рисуется только через каналы I–II |
| III.7 Алевропелиты как литология | Нет литологической карты в признаках; рельеф и радар — косвенные заменители; фации — только формула и только восточнее 105° |
| III.8 Грубообломочные породы, концентрация зёрен Au | То же; концентрация зёрен — шлихи (заверка) |
| III.9 Кварц-карбонатные жилы | Мельче ячейки; `ast_carb` на листе не различает жилы; возраст жил неизвестен |
| Перенос Au (обломочный / растворённый) | Процесс, а не объект; направление переноса без палеорельефа не восстановить |
| Ловушка, механизм осаждения | В v2 не описана; данных о восстановительных барьерах (углеродистое вещество, сульфиды) нет |
| Возраст этапов | Геохронологии в проекте нет |
| Слои формулы западнее 105° (листы R-48-IX,X и запад R-48-XV,XVI) | Многолистовая сборка ГИС Интегро заканчивается на 105° в.д. |
| Магнитное поле на R-48-IX,X | Грав-магнитной съёмки там нет |
| Контакт чехол / фундамент на широкой территории | `svita_new` есть только на основном листе; граница щита 1:5 млн — только для обзора |
