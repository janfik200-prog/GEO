## Оговорки аудитора
1. Рельеф для UTS1 — не независимый свидетель: линии UTS1 взяты по теням зимнего S2, тень — это рельеф. Подтверждает «под линией есть форма», не «это линеамент».
2. Одна нормаль на линию (PCA): кривые линии занижают π̂. Поперечный разброс / длина: UTS1 0,23, RELU1 0,31, LINB2 0,35 — наборы между собой по π̂ не сравниваются.
3. Ориентационный критерий слабый (на нуле проходится сам); информативен разрыв: верхний край после n↔t ниже нижнего края исходного у всех наборов (LINB2: +4 против +33).
4. Расхождения кода: проверка-утверждение переноса тавтологична; тор — одно зерно бутстрепа; ориентационный вердикт выносится по логу, не кодом. На вердикты не влияют.
5. По сравнению с REAL1 (смещённая оценка) числа ниже на 12–14 п. п. — согласуется с найденным там смещением.
