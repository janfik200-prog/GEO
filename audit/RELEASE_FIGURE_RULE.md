# Правило выбора окон для рисунков релиза (WP21, ТЗ v3.0)

Записано 28.10.2026, **до построения рисунков**. После просмотра правило не
меняется. Плохое окно остаётся, причина пишется в `figure_manifest.md`.

## 1. Обзорные карты (вся площадь листа)
Выбора нет: показывается весь лист.
- Подложка — зимний B04, растяжка 2–98 % по листу.
- Линии — финальный набор C_all из GeoPackage.
- Для Лапландии и Finland65 GTK 292 стоит на **отдельной панели** с подписью
  «оценка, не вход».

## 2. Увеличенные окна 5 × 5 км
- **Анабар и Лапландия** — те же окна, что в Пакете 01: правило
  `audit/SELECTION_RULE.md`, `outputs/k1/figures/selection_manifest.csv`.
- **Finland65** — то же правило, что для Лапландии: два случайных окна из
  допустимых, `default_rng(20261026)`, 100 % валидных ячеек, без страт.

## 3. Сравнение методов в одном окне (сцена D)
- Окно 5 × 5 км в центре участка 20 × 20 км из таблицы D09
  (`D09_F1_AUDIT_*.csv`, бюджет «полная длина», эталон v2).
- Берутся **два участка на площадку:**
  - с наибольшей разностью F1 «наша − LSD» — удачный;
  - с наименьшей разностью — сложный.
- Одинаковые разности решаются меньшим tile_id.
- Карты: наша при своей длине; Хаф, обрезанный до длины нашей карты; LSD при
  своей (он короче).
- Выбор идёт по числу из таблицы, а не по виду окна. Таблица была видна до
  записи правила, поэтому это **иллюстрация, а не выборка для оценки.**
